# Google Sites Search & PDF Summary Agent (`sites-search-agent`)

An ADK (Google Agent Development Kit) agent built and deployed with [`agents-cli`](https://pypi.org/project/google-agents-cli/) that searches enterprise Google Sites and generates downloadable **1–2 page binary PDF executive summaries** (`application/pdf`).

When registered in **Gemini Enterprise**, any PDF generated by this agent via `tool_context.save_artifact()` is attached to the Gemini Enterprise conversation turn as an `AI_GENERATED` session file and automatically harvested by [`ge-ediscovery-logging`](../README.md) into Cloud Storage and BigQuery (`conversation_turns`).

---

## Key Capabilities & Tools

Defined in [`app/tools.py`](./app/tools.py) and wired into [`app/agent.py`](./app/agent.py):

1. **`search_google_sites(query, page_size, tool_context)`**:
   - Queries Vertex AI Search / Discovery Engine data stores for internal enterprise Google Sites content and embedded presentations.
   - Falls back gracefully to the model's domain knowledge when a user asks for a summary on a general topic not present in the internal Sites data store.

2. **`generate_pdf_summary(title, subtitle, executive_summary, sections_markdown, key_takeaways, filename, tool_context)`**:
   - Uses [`fpdf2`](https://py-pdf.github.io/fpdf2/) to render a publication-quality 1–2 page PDF with a styled header banner, executive summary callout box, structured section headings/bullets, key takeaways, and page-numbered footers.
   - Saves the binary PDF (`application/pdf`) directly into the ADK session artifact store via:
     ```python
     pdf_part = types.Part(
         inline_data=types.Blob(
             mime_type="application/pdf",
             data=pdf_bytes,
             display_name=clean_name,
         )
     )
     await tool_context.save_artifact(filename=clean_name, artifact=pdf_part)
     ```
   - When invoked through **Gemini Enterprise** (`streamAssist`), the saved artifact is surfaced as a downloadable session file (`fileId`) and captured by `ge_harvest.py` with `file_source = "AI_GENERATED"`, `mime_type = "application/pdf"`, `byte_size`, `sha256`, and `gcs_uri`.

## Quick Start

### 1. Configure Environment Variables

Copy `.env.example` to `.env` and set your Google Cloud project placeholders:

```bash
cp .env.example .env
```

```dotenv
GOOGLE_GENAI_USE_VERTEXAI=true
GOOGLE_CLOUD_PROJECT=your-gcp-project-id
GOOGLE_CLOUD_LOCATION=global

# Optional: Discovery Engine Google Sites Data Store configuration
# GOOGLE_SITES_PROJECT_NUMBER=your-gcp-project-number
# GOOGLE_SITES_DATASTORE_ID=your-google-sites-datastore-id
# GOOGLE_SITES_FALLBACK_ENGINES=your-fallback-engine-id
```

### 2. Install & Test Locally

```bash
# Install dependencies
agents-cli install

# Run unit & integration tests (verifies binary %PDF-1.x generation)
uv run pytest tests/unit tests/integration/test_agent.py

# Run single-turn CLI test
agents-cli run "create a PDF summary for me of Quantum Computing"

# Launch interactive ADK web playground
agents-cli playground

# Run LLM-as-judge evaluation suite
agents-cli eval run
```

### 3. Deploy to Vertex AI Agent Runtime & Register with Gemini Enterprise

```bash
# Deploy (or update an existing Reasoning Engine in-place)
agents-cli deploy \
  --project <your-gcp-project-id> \
  --region us-central1 \
  --service-name sites_search_agent \
  --update-only

# Or register with Gemini Enterprise
agents-cli publish gemini-enterprise
```
