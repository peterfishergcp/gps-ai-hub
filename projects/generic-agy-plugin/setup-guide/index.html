Troubleshooting FAQ

Quick fixes for the most common setup questions.

“Your current account is not eligible for Antigravity”

You clicked Continue with Google instead of Use Business Account on the welcome screen, or selected a personal Gmail profile in the browser instead of your official organizational account. Return to the Welcome screen, click Use Business Account → Continue with Google Cloud, and choose your organizational email.

“No Gemini Enterprise license was found for this project and location”

Double-check three settings on Select Billing Model: (1) Subscription is selected at top-left (never Pay As You Go), (2) the Project ID matches the exact lowercase GCP Project ID provided by your IT administrator (with hyphens, no trailing spaces), and (3) the correct region (such as United States) is selected under Choose Region.

Browser didn't open or “Open Antigravity” didn't redirect back to the app

If Chrome or Edge opened in a personal profile, sign in to your organizational Google Cloud Identity account in that browser first, or use the Copy sign-in link option on the Antigravity sign-in card to paste the link directly into your organizational browser window.

Python is not installed yet when running the Hello World test

That's completely normal on a fresh corporate workstation! Antigravity still creates main.py and shows you how to run it when Python is available—your Antigravity setup and Gemini Enterprise license are already 100% active. Plus, all 28 Generic AGY Plugin skills run with zero Python required.
