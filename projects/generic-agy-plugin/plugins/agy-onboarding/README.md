# Skills — Onboarding, Daily Brief, Voice & Token Telemetry (`agy-onboarding`)

Day-1 productivity, token telemetry, and onboarding skills for Public Sector staff using **Google Antigravity** alongside their **Gemini Enterprise (`GE`)** subscription and **Personal Memory** (`~/.gemini/config/plugin_data/my-antigravity/memory/`).

## Included Skills (8)
- **`/agy-onboard`** — 60-second interactive setup for your agency role, personal voice preferences (`voice.md` / `agy-profile.md`), optional 1-step **Personal Memory** initialization (`public-sector` preset), and Gemini Enterprise instance handoff, plus 30-60-90 day onboarding & SOP playbooks.
- **`/model-guide`** — Practical guide to switching models in Antigravity Desktop, IDE, and CLI (`agy`)—including **Anthropic Claude (`Claude Sonnet` & `Claude Opus`)** alongside **Google Gemini**, Thinking/Reasoning effort levels, Dual-Model Cross-Reviews, Vertex AI Model Garden IT enablement, and state quota/compliance guardrails.
- **`/orchestrator-guide`** — How best to use **`Orchestrator (Neon / Argon / Carbon)`** (`Planner` + `Gemini 4 Hydrogen` `Executor`) across Antigravity App and CLI (`agy`) to complete complex multi-file workflows faster while conserving quota.
- **`/token-usage`** — Retrieves exact 5-hour, 24-hour, and 7-day local token telemetry (`input`, `cache_read`, `output`) and renders an interactive HTML consumption dashboard in chat and `Extensions -> Preview`.
- **`/daily-brief`** — Unified morning kickoff brief, calendar prep, and weekly rollups combining your federated GE connectors (Outlook/Gmail, SharePoint/Drive, Teams) and Personal Memory (`P0`/`P1` Action Items, active 4-file initiatives, and `>21d` stale stakeholder alerts).
- **`/my-voice`** — Draft replies, decision memos, formal letters, constituent responses, and plain-language rewrites calibrated to `~/.gemini/config/plugin_data/my-antigravity/memory/profile/voice.md` (strictly draft-only; pairs with `/no-ai-slop` and `/outbound-scrub`).
- **`/inbox-triage`** — Rule-driven email and incident report triage separating immediate leadership escalations from routine items, with a fail-safe hold on unreadable attachments.
- **`/agy-update`** — Fast Git / HTTPS SHA-256 updater to pull newly published Public Sector skills and sidecars in under 2 seconds.
