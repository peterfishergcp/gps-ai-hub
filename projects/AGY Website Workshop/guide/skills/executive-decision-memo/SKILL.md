# One-Page Executive Decision Memo

Use this skill whenever the user asks to turn rough options, project trade-offs, or briefing notes into an executive decision memo.

## Workflow & Rules

1. **PII & Sensitive Data Check First**: Halt and request redaction if real individual PII or credentials appear in the input notes.
2. **Five Concise Headings (One Page Maximum)**:
   1. **Decision Needed** (state the exact decision and target date in 1–2 sentences)
   2. **Background** (maximum 5 sentences; mark any unverified budget figure or metric inline as **`[NEEDS CONFIRMATION: figure]`**—never invent numbers)
   3. **Options Considered** (compare 2–3 options neutrally with primary benefit, primary risk, and resource impact)
   4. **Recommendation** (clear choice and rationale)
   5. **Next Steps Upon Approval** (owner-ready checklist)
3. **Human Verification Footer**:
   - End with sources used and: *"AI-assisted executive memo. Confirm all budget figures, timelines, and statutory/policy citations before leadership submission."*
